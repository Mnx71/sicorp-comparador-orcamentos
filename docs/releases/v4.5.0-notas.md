# SICORP v4.5.0 — Distribuição oficial

**Data:** 05/11/2026

Versão final do Sistema de Comparação de Referenciais de Preços (SICORP), aplicação HTML que funciona localmente no navegador, sem instalação.

### Arquivos para baixar
- `SICORP_v4.5.0_USUARIO.zip`: programa HTML e manual do usuário, com instruções de abertura.
- `SICORP_v4.5.0_TECNICO_RECUPERADO.zip`: programa, fontes extraídos do HTML, reconstrução verificável, testes de integridade e documentação técnica.
- `sicorp_comparador_orcamento_v4.5.0.html`: programa individual, para uso offline.
- `SICORP_Manual_Usuario_v4.5.0.pdf`: manual do usuário, com 10 páginas e imagens reais.
- `SICORP_Relatorio_Entrega_Validacao_v4.5.0.pdf`: relatório de entrega e validação.

### Principais recursos
Conferência de orçamentos e bases, comparação de preços, categorias e filtros, exportação de resultados e tutorial interativo de acompanhamento.

### Integridade da aplicação
SHA-256 do HTML: `33807e74bdb45c0bb081bb2001a40cb1c16394144dfad7c9930e2cde4aaa6905`.

### Limitações registradas
O pacote técnico original não foi recuperado: o pacote técnico desta release é uma reconstrução dos fontes a partir do HTML final, e não substitui a organização e o histórico originais. Os testes automáticos de recuperação não reproduzem integralmente os 400 testes e 27 verificações agrupadas relatados no ambiente anterior. A versão 4.4.0 foi preservada no repositório.
